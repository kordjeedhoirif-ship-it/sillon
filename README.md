# Sillon

Trouve des morceaux à la sonorité proche d'un titre que tu aimes.

Sillon écoute l'extrait du morceau, mesure son tempo, sa tonalité, son timbre et son énergie (avec [Essentia.js](https://mtg.github.io/essentia.js/)), puis classe des dizaines de candidats issus de Deezer, Apple Music et Last.fm selon leur ressemblance sonore. Tout se passe dans le navigateur, sans IA ni compte.

**Utiliser Sillon :** https://kordjeedhoirif-ship-it.github.io/sillon/

Fonctions : analyse sonore, plusieurs morceaux de référence, analyse d'un fichier audio personnel, apprentissage par 👍/👎, favoris, historique, installation comme application (PWA).
